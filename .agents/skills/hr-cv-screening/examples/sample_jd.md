# Job Description mẫu — Senior Frontend Developer

## Vị trí: Senior Frontend Developer

### Thông tin chung
- **Công ty**: HiLab Technology
- **Địa điểm**: TP. Hồ Chí Minh (Hybrid)
- **Loại hợp đồng**: Toàn thời gian
- **Mức lương**: Thỏa thuận (25-40 triệu)

### Mô tả công việc
- Phát triển và duy trì các ứng dụng web sử dụng React/Next.js
- Thiết kế kiến trúc frontend cho các dự án mới
- Code review và mentor cho junior developers
- Phối hợp với team Backend và Design để deliver features
- Tối ưu performance và user experience
- Viết unit tests và integration tests

### Yêu cầu bắt buộc
- **Kinh nghiệm**: Tối thiểu 3 năm kinh nghiệm với React.js
- **Kỹ năng kỹ thuật**:
  - Thành thạo React.js, Next.js
  - Thành thạo TypeScript
  - Kinh nghiệm với state management (Redux, Zustand, hoặc tương đương)
  - Hiểu biết về RESTful API và GraphQL
  - Kinh nghiệm với CSS-in-JS hoặc Tailwind CSS
  - Kinh nghiệm với Git
- **Học vấn**: Tốt nghiệp Đại học chuyên ngành CNTT hoặc tương đương
- **Ngôn ngữ**: Tiếng Anh giao tiếp tốt (đọc hiểu tài liệu kỹ thuật)

### Yêu cầu ưu tiên
- Kinh nghiệm với CI/CD (GitHub Actions, Jenkins)
- Kinh nghiệm với testing frameworks (Jest, Cypress, Playwright)
- Kinh nghiệm với Design System / Component Library
- Hiểu biết về Web Accessibility (a11y)
- Kinh nghiệm với Agile/Scrum

### Quyền lợi
- Lương tháng 13 + thưởng performance
- Review lương 2 lần/năm
- Bảo hiểm sức khỏe premium
- Laptop công ty
- Budget học tập hàng năm
- Flexible working hours
